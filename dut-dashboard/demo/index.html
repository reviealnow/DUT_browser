What is real here, and what is not

Tiles marked measured carry numbers from real DUT sessions — CPU and memory counters, associated-client counts, per-channel neighbour counts, the channel recommendation, the file listing of an actual downloaded bundle. Every SSID, BSSID, MAC and IP in them was replaced before commit: a neighbour scan sweeps up the networks of everyone in radio range, not just ours. The replacement is deterministic and one-to-one, so counts and shapes are untouched and only labels change.

Tiles marked synthetic content are invented end to end. A file list and a note board are content, not measurements — there is no reading to stay faithful to, and the real ones on this bench are test scaffolding carrying colleagues' names.

Fleet is invented too, for a different reason: a bench with one DUT attached cannot produce a fleet, and a mesh backhaul needs at least two, so there is no reading to be faithful to. Its shape is the product's — both capture directions, every field the DUT reports about the link, and which control each card offers.

Upgrade Firmware is labelled apart from those two, because only its content is invented. Image names, checksums and the device address are made up, and no upload, no backend validation and no DUT are behind the buttons — but the rule the screen exists to teach is the product's, taken from firmware_service.py: the management API takes the encrypted image and the web-UI path takes the signed .sig, refused in that order, with an unrecognised filename deliberately let through. Getting that pairing wrong is what cost a real bench session.

A ◇ concept chip marks an idea shown for discussion. Anything without one mirrors what the product actually does — which cuts both ways: the demo must not invent a capability, and it must not quietly show a cruder one either. Each page ends with a line saying where its own numbers came from.

Showing this to someone

Open Site Survey first — 2,438 real networks across two bands is the fastest way to make the point that this is a measurement tool. Then Overview for the fleet and the 40-hour trends, and Downloads to show what an operator actually walks away with. Files is the one to hand over: drag a file from the desktop onto it.

Every file works on its own, so you can send just the one that answers the question you were asked. They only need each other for the sidebar links, which expect them in the same folder.
