Why every row reads “miss”. This card reconciles two sources: the DUT's own hostapd config, read over serial (Source A), and a scan run on the host machine (Source B), which needs SURVEY_WIFI_IFACE set. The bundle behind this page has Source A only, so the product shows exactly this — every VAP unmatched and a Source B unavailable badge. Inventing a Source B would mean inventing the reconciliation the card exists to perform.
